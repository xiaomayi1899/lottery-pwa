先说实话

开奖是相互独立的随机事件。任何软件、任何模型都不能提高双色球 / 大乐透的中奖概率——本工具的 12 步模型是对历史数据的统计整理与输出练习，它的价值是让你看清概率与期望（比如单注期望净收益为负、长期购彩必亏），而不是预测号码。

竞彩足球部分是概率估计工具：从官方赔率反推市场概率、跨玩法互证、泊松比分分布、价值与 Kelly 计算。它衡量的是赔率是否划算，不是结果的保证。

仅对接国家官方彩票（中国福利彩票、中国体育彩票）公开数据，仅限个人学习与娱乐用途。

安装到 iPhone 主屏幕
  1. 用 Safari 打开本页（扫码或输入电脑显示的地址）
  2. 点底部工具栏的「分享」按钮
  3. 选择「添加到主屏幕」 → 确认
  4. 以后从主屏幕图标打开，就是全屏独立 App
局域网地址二维码（电脑开着服务时可用；若路由器开了 AP 隔离，请改用热点或公网地址）

提示：局域网 http 打开时无离线缓存；用「启动公网访问.bat」生成的 https 地址添加到主屏幕，可支持离线打开与自动更新。

数据来源

双色球：中国福利彩票发行管理中心官方接口；大乐透 / 竞彩：中国体育彩票官方接口。数据由本机服务或 GitHub 每日自动任务更新，双彩历史快照生成于 —；发布为 GitHub Pages 后，手机用流量即可访问，无需电脑开机。

开奖结果可在 cwl.gov.cn（福彩）与 sporttery.cn（体彩）官网核对。

算法与开源致谢

号码彩 12 步模型引擎（超几何分布、贝叶斯后验、卡方检验、马尔科夫链、蒙特卡洛、凯利准则、大数定律）移植自本机「双彩智投」项目，两端随机序列一致、结果同构。

竞彩泊松模型与去水 / Kelly 口径参考开源项目 penaltyblog（GitHub） 等公开实现，全部在本页本地计算，无第三方运行时依赖、不上传任何数据。

理性购彩

购彩是娱乐消费，不是投资。只花娱乐预算，不加仓、不借钱、不追号。未满 18 周岁不得购彩；如感觉沉迷，可拨打公益热线 400-858-1838。
