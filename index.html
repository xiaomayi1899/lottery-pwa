先说实话

开奖是相互独立的随机事件。任何软件、任何模型都不能提高中奖概率——本工具的走势形态分析是对历史数据的统计整理与输出练习，它的价值是让你看清概率与期望（单注期望净收益为负、长期购彩必亏是大数定律下的必然），而不是预测号码。

仅对接国家官方彩票（中国福利彩票、中国体育彩票）公开数据，仅限个人学习与娱乐用途。

推荐逻辑（近 50 期走势形态）

选号型彩种（双色球 / 大乐透 / 快乐8）：从和值 · 奇偶 · 质合 · 大小 · 区间 · 012路 · 走势图模式（重号 / 邻号 / 斜跳）· 冷热遗漏等基础维度统计，预测下期形态，再在形态约束下按「综合 / 热号 / 回补 / 均衡」四种评分视角合成推荐，另附纯随机对照。

数字型彩种（福彩3D / 排列五）：各位走势 + 和值 + 奇偶大小 + 012路 + 跨度（3D 含组选形态）→ 形态约束下合成直选推荐。

这些维度本身没有预测力，价值在于把信息结构化、把概率看清楚。算法思路参考开源项目 lottery-ai-simulator（热号/冷号/遗漏/统计特征生成候选） 与 lucky_ball（历史数据分析） 等，全部在本页本地计算，无第三方运行时依赖、不上传任何数据。

安装到 iPhone 主屏幕
  1. 用 Safari 打开本页（扫码或输入电脑显示的地址）
  2. 点底部工具栏的「分享」按钮
  3. 选择「添加到主屏幕」 → 确认
  4. 以后从主屏幕图标打开，就是全屏独立 App
局域网地址二维码（电脑开着服务时可用；若路由器开了 AP 隔离，请改用热点或公网地址）

提示：局域网 http 打开时无离线缓存；用「启动公网访问.bat」生成的 https 地址添加到主屏幕，可支持离线打开与自动更新。

数据来源

双色球 / 福彩3D / 快乐8：中国福利彩票发行管理中心官方接口；大乐透 / 排列五：中国体育彩票官方接口。数据由本机服务或 GitHub 每日自动任务更新，全量快照生成于 —；发布为 GitHub Pages 后，手机用流量即可访问，无需电脑开机。

开奖结果可在 cwl.gov.cn（福彩）与 sporttery.cn（体彩）官网核对。

理性购彩

购彩是娱乐消费，不是投资。只花娱乐预算，不加仓、不借钱、不追号。未满 18 周岁不得购彩；如感觉沉迷，可拨打公益热线 400-858-1838。
