# 彩票预测助手 (lottery-pwa)

双色球 / 大乐透 12 步概率模型 + 竞彩赔率互证 · 免电脑、手机直用的 PWA。

**在线使用**：<https://xiaomayi1899.github.io/lottery-pwa/>
（iPhone Safari 打开 → 分享 → 添加到主屏幕，即得全屏 App；断网可离线打开）

## 功能

- **双色球 / 大乐透**：16 个异构模型（超几何、贝叶斯、卡方、马尔科夫、蒙特卡洛、凯利、大数定律 + 时间衰减热度、形态匹配、共现聚类、模拟退火），逐期走前回测自动加权投票合成，输出五注策略
- **竞彩足球**：官方赔率去水、跨玩法互证、Dixon-Coles 修正泊松、赔率变动信号、基本面（排名 / 近况 / 交锋）、让球模型价值、信心星级、当日串关参考
- **数据自动更新**：GitHub Actions 每天北京时间 21:40 / 22:10 抓取福彩 / 体彩官方接口并提交；大乐透与竞彩赔率由手机实时直连官方
- **PWA**：可安装、离线缓存、桌面图标

## 本地运行（可选）

```bash
python -X utf8 server.py        # 电脑服务模式（局域网 / 公网隧道）
python -X utf8 update_data.py   # 手动更新数据
```

仅使用 Python 标准库；前端无任何第三方运行时依赖。

## 诚实声明

**开奖是相互独立的随机事件，任何软件与模型都不能提高中奖概率。**
本工具仅用于概率统计学习与理性购彩参考：单注期望净收益为负、长期购彩必亏是大数定律下的必然。请只花娱乐预算，未满 18 周岁不得购彩。仅对接国家官方彩票公开数据。
